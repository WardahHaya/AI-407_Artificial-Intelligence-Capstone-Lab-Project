Lab 8 API Test Results
======================

Environment:
- FastAPI app created with create_app(model=ApiDemoModel()) for deterministic local verification.
- Endpoints tested locally with FastAPI TestClient.

POST /chat
----------
Example curl:
curl -X POST http://127.0.0.1:8000/chat ^
  -H "Content-Type: application/json" ^
  -d "{\"message\":\"Did any recruiter ask for my updated resume?\",\"thread_id\":\"lab8-thread-1\"}"

Observed response:
Status: 200
{"thread_id":"lab8-thread-1","message_id":"322bdb7e-ae4a-41f1-a514-51db2d5e5409","final_answer":"I found the recruiter request in grounded memory. Talent Team asked for the updated resume before May 6 and requested interview availability.","status":"completed"}
